### 🧑‍💻 Who am I?

I'm **Ritom Ghosh** — a 19-year-old software developer who's been writing code since age 14. I started by modding Minecraft (Java/Kotlin), survived a Unity/C# phase, dabbled in C++, and eventually found my true calling in **Dart** and cross-platform mobile development.

Five years in and I still find it hard to close the laptop. Fuelled by ideas, cold beverages, and the eternal pursuit of the perfect app architecture.

- 🎮 **Origin story:** Minecraft forge mods — that's where `public static void main` stopped being scary
- 💜 **Favourites:** Dart & Kotlin (Java is where it started, Kotlin is where it lives)
- 📱 **Current obsession:** Building full-stack mobile apps with Flutter, React Native & Supabase
- 🔒 **Dream project:** The most private, user-respecting social app ever built
- 🌐 **Website:** [ritom.site](https://ritom.site)
